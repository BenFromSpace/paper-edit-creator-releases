# Paper Edit Creator

Paper Edit Creator is Right Hand Films' Mac app for preparing interview footage, transcribing interviews, and creating paper edits.

## Requirements

- A Mac with Apple Silicon and macOS 13 or later.
- An authorized Google Workspace account.
- An internet connection for sign-in, transcription, paper edits, and quote chat.

## Install

1. Download the DMG from the [latest release](https://github.com/BenFromSpace/paper-edit-creator-releases/releases/latest).
2. Open the DMG and drag Paper Edit Creator into Applications.
3. Open Paper Edit Creator from Applications and sign in.

## Using the app

Follow the stages across the top: Project Details, Prep Footage, Transcribe, and Paper Edit. Use one video clip per interview. Each stage unlocks when the previous stage is complete.

Projects save automatically on your Mac. This version removes local app projects 10 days after creation, so copy finished paper edits into your project documents before then.

When an update is available, the app shows an update button.

This repository contains installers and update information for Paper Edit Creator.
